🚀 快速启动:
1. 初始化数据库:
   mysql -u root -p douyin < blog-sql/init_blog.sql

2. 启动博客服务:
   cd base-service/cmd/blog
   go run main.go

3. 启动API网关(另开终端):
   cd douyin-api/cmd
   go run main.go

4. 测试接口:
   curl http://localhost:8080/blog/list
